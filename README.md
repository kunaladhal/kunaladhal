## 🚀 Projects

### 🍃 EcoTrack Ecosystem — Waste Management, Green Marketplace & Carbon Tracking
**Tech Stack:** Flutter, Dart, Firebase (Firestore/Auth), Cloudinary, Google Maps, Geolocator, Groq API (llama-3.1-8b-instant)

A multi-platform sustainability solution with two apps:
- **Client App:** Role-based dashboards for Citizens, Waste Collection Workers, and Eco-Sellers — AI waste-segregation chatbot, carbon footprint calculator, green marketplace with Razorpay payments, gamified eco-points, geo-tagged waste complaints, and a community forum.
- **Admin Panel:** Real-time analytics with `fl_chart`, centralized complaint map, and intelligent nearest-worker auto-assignment (Haversine-based 10km radius filter).

Built with clean architecture, `flutter_bloc` state management, and repository pattern abstraction.

### 🛍️ Cara — Modern Responsive E-Commerce Website
**Tech Stack:** HTML5, CSS3, JavaScript (ES6+)

A fully responsive, multi-page fashion e-commerce site built during a Frontend Web Development internship — featuring a dynamic sidebar navbar, interactive product image gallery, shopping cart layout, and a semantic, framework-free codebase using Flexbox & CSS Grid.
